# 0007 — Java 25 baseline

- **Status:** accepted (2026-11-26); amended 2026-11-27 to the Paper 1.21.11+ baseline (runtime floor unchanged)

## Context

login-core requires JDK 25 and emits Java 25 bytecode. pvp-core uses Java 25 toolchain but `options.release=21` for backward compat with Paper 1.21.11. login-core does not need that compat floor even though its target is now Paper 1.21.11+ (`paper-api:1.21.11-R0.1-SNAPSHOT`, `api-version: '1.21.11'`): a Java 25 runtime remains mandatory. The 26.3 server is only a local/dev test server, not the production target.

## Decision

- Gradle toolchain: Java 25. Compilation target: Java 25. Generated bytecode: Java 25. Minimum runtime: Java 25.
- Do not set `options.release=21` (unlike pvp-core). Either omit release or set `release=25`.
- Java 25 is a hard floor; compile against `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT` with `api-version: '1.21.11'`; minimum runtime Java 25.
- Document Java 25 as a hard runtime requirement in README, AGENTS.md and this ADR. `plugin.yml` has no Java-version field, so no Java requirement is claimed there.

## Consequences

- The jar cannot run on Java 21 runtimes, even on Paper 1.21.11 (which itself permits Java 21). Document clearly.
- No need for reflection-based version shims for Java 21/25 differences.
- Build fails fast if JDK 25 absent.
