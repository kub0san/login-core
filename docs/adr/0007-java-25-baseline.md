# 0007 — Java 25 baseline

- **Status:** accepted (2026-11-26)

## Context

login-core requires JDK 25 and emits Java 25 bytecode. pvp-core uses Java 25 toolchain but `options.release=21` for backward compat with Paper 1.21.11. login-core does not need that compat floor (target is Paper 26.3, min 1.21.11 but no Java 21 runtime requirement).

## Decision

- Gradle toolchain: Java 25. Compilation target: Java 25. Generated bytecode: Java 25. Minimum runtime: Java 25.
- Do not set `options.release=21` (unlike pvp-core). Either omit release or set `release=25`.
- Paper 1.21.11 API is the minimum compilation baseline; compile against appropriate API version.
- Document Java 25 as a hard runtime requirement in README and plugin.yml.

## Consequences

- Plugin cannot run on Java 21 runtimes. Document clearly.
- No need for reflection-based version shims for Java 21/25 differences.
- Build fails fast if JDK 25 absent.
